## 使用方式

- 点击顶部扩展菜单里的 **SoulLink** 图标打开面板。
- 右下角常驻悬浮球：单击打开面板，拖拽可移动（位置自动记忆），长按 650ms 隐藏。
- 关闭面板后悬浮球会重新出现，保证随时有入口。
- 打开面板后默认进入首页启动器，点击「API 连接」图标进入配置页：填入 OpenAI 兼容接口的 Base URL 与 API Key，点击「连接并拉取模型」即可拉取模型列表并选择模型；部分不支持 /models 的渠道可手动填写模型名称。
- 首页第二个图标「日志系统」：打开后台日志控制台，实时观察程序运行状态，方便 DEBUG。捕获范围：`console` 输出、未捕获的 `window` 错误与 Promise 拒绝、Tavern 宿主关键事件（聊天切换 / 生成开始结束 / 设置加载等）、以及 SoulLink 自身的关键操作（启动、菜单注册、API 连接等）。
- 日志控制台支持：按级别筛选（全部 / 调试 / 信息 / 警告 / 错误，带实时计数）、关键词搜索、暂停 / 继续追加、自动跟随最新（滚动回顶部时出现「回到最新」按钮）、清空、复制为纯文本、导出完整 JSON 文件；内存保留条数可调（默认 2000 条，环形覆盖最旧日志）。首页日志卡片会实时显示已记录条数与错误数。
- 其他扩展如需写入日志，可调用全局 `SoulLinkLog.info / warn / error / debug`（或 `SoulLinkLog.log`）。
